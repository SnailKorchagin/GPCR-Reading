# GPCR · 《贺新郎·读史》新解

这是 SnailKorchagin 的个人原创写作项目。

**GPCR** 是 **Great Proletarian Cultural Revolution** 的缩写。

九章从“人猿相揖别”写到“歌未竟，东方白”，围绕《家庭、私有制和国家的起源》与《贺新郎·读史》，讨论劳动、共同体、家庭、私有制、阶级、国家与人的解放。
